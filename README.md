# Ransomeware Attack Response in Healthcare
This project outlines a comprehensive plan for preparing for, detecting, and responding to a sophisticated ransomware intrusion, based on the fictionalized case of HarborPoint Health.Problem Statement  HarborPoint Health, a regional healthcare system, experienced a ransomware attack that encrypted key clinical systems (EHR, PACS) and exfiltrated patient data, resulting in extended operational disruption, a forced switch to paper workflows, and significant financial and reputational damage. The success of the attack was due to specific pain points:  Detection Latency: Initial foothold went unnoticed. Incomplete Segmentation: Flat network segments allowed for rapid lateral movement. Backup Gaps: Backups were accessible or insufficiently tested, hindering fast recovery. Coordination & Communications: Lack of a practiced playbook slowed incident response. Core Objectives  The project aims to improve cyber resilience and minimize clinical/financial impact with the following measurable goals:  Reduce Detection-to-Containment Time: Target ≤ 1 hour for high-severity incidents. Ensure Recovery: Eliminate single points of failure with an immutable, offline backup strategy for EHR/PACS, validated quarterly. Limit Spread: Achieve network micro-segmentation that restricts ransomware lateral movement to ≤ 3 hosts per incident. Enhance Detection: Implement signature- and behavior-based detection using Splunk SIEM, YARA, and EDR. Operationalize Threat Intel: Integrate the Malware Information Sharing Platform (MISP) for automated ingestion and sharing of Indicators of Compromise (IoCs).
